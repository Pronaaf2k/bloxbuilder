# SELISE Blocks Cloud Getting Started

Source: `https://docs.seliseblocks.com/cloud/getting-started`

## Highlights

- Users can sign up with email or supported SSO providers including GitHub, Google, Microsoft, LinkedIn, and X.
- Blocks Cloud project creation supports optional GitHub repository connection and environment selection.
- Deployment expects matching repository branches for environments such as `dev`, `test`, `stg`, `iat`, `uat`, `prod-shadow`, `pre-prod`, and `main`.
- Project settings are organized around Environments, People, Repositories, and Settings.
- Owners manage project membership, environment access, and ownership transfer.
